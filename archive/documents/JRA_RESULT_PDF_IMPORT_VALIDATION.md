# JRAレース結果PDFインポート検証

## 対象

- `sample/レース結果一覧　JRA.pdf`
- `sample/レース結果一覧　JRA_2.pdf`

## 検証結果

2026-08-04時点のJRA結果PDF解析器で、上記2ファイルをPDFテキスト抽出結果に対して検証。

- サンプル1: 12レース検出
- サンプル2: 12レース検出
- 両サンプルとも各レースの開催日・競馬場・R番号を取得
- 1～3着の馬番を取得
- コース種別・距離を取得
- レース名を取得
- 払戻金の各式別を取得
- ページをまたぐ結果表・払戻表を処理
- `せん` 表記の馬も着順解析対象に対応

## 主な修正点

1. PDF.jsの同一行TAB区切りを保持して払戻表を解析。
2. 「払戻金」見出しが払戻表の後ろに出るJRA PDF構造に対応。
3. レース開始を「開催日＋競馬場＋発走時刻」で検出。
4. レース結果が次ページに続く場合も同じレースとして継続。
5. 払戻表の横3列レイアウトを、明示見出し・前後行の式別情報から解析。
6. `牡`・`牝`・`せん`・`セ`・`騸` の性別表記に対応。
7. 未登録レースは既存の `/api/races/results-import` により、レース情報・出走馬・着順・払戻をまとめて新規登録する既存仕様を維持。
