## クラスタN: 道悪(馬場)を予想に入れる — 保留(2026-10-26。データが増えたら試算し直す)

ユーザーの考え: 道悪では有利な枠・展開が変わり、道悪巧者・良馬場専門の馬も実在する。当日の馬場を予想登録画面で入れ
(基本は管理者、ユーザーごとに上書き)、推奨馬に反映したい。2026-10-26 の試算では効果がはっきりせず、
**原因は各馬の道悪の走が少ない(アプリの成績は主に2025年以降。1頭あたり道悪3〜5走)ことと判断して保留**にした。

### 2026-10-26 の試算の結果(比率を選ぶのに使っていないレースの指数で、道悪のレースだけ)
- **全体の傾向(集計用キャッシュ race_lineup_cache。8頭以上)**: 脚質(逃げ・先行が有利)は馬場でほぼ変わらない。
  馬番は、中央ダートで道悪になると内枠の不利が消え(3着内率 内 良19.0% → 重・不良21.2%)、地方ダートは逆に内が悪くなる(27.6% → 24.8%)。
  中央芝はほぼ変わらない。
- **馬番の要素を同じ馬場の組の成績にする**: 並びの一致(3着以内の馬の点が4着以下より高い割合)がダートで +1〜2ポイント
  (中央ダート重・不良 49.1% → 50.4%、地方ダート稍重 48.2% → 50.7%)、芝は悪化。馬番の要素自体が弱い(50%前後)ので推奨馬への影響は小さい。
- **馬ごとの道悪の得意度(道悪の3着内率 − 良の3着内率)を軸指数に足す**: 足すほど悪化(確かめる側の◎複勝圏 43.8% → K=10 で 40.6%)。
- **差がはっきりした馬だけ(道悪・良とも3走以上、差25/35/50%以上)を ±3〜10点**: ほぼ変わらないか悪化。判定した「道悪巧者」の
  道悪での3着内率は 20〜31%、「良馬場専門」は 17〜43% で、全馬(26〜27%)と差が無い=今の走数では見分けられない。

### 試算し直すとき(目安: 1頭あたりの道悪の走が増えた頃。例えば2027年の秋)
1. 本番から読むだけで、対象のレース(例: 南関東の各コース・重賞)の出走馬の全戦績(`race_results` を horse_key で90頭ずつ。
   採点の `scoreRaces` と同じ問い合わせ)と、レースの馬場(races_index_cache)・勝ちタイム(race_time_cache)を書き出す。
   2026-10-26 は約1,700レース・出走馬7,150頭で読み取り約13万行。
2. 指数は「比率を選ぶのに使っていないレース」のものを使う(南関東は前半で比率を選んで後半に当てはめる・前後を入れ替える。
   重賞は1年ずつ外す。`public/pace-search.js` の `choosePaceWeights` を手元で動かす)。
3. 試す側・確かめる側に分け、道悪のレースだけで ◎の3着以内・並びの一致を比べる。**判定した道悪巧者・良馬場専門の、実際の道悪での
   3着内率が全馬の平均とはっきり違うか**を最初に見る(違わなければ足し引きしても効かない)。
4. 効くなら、当日の馬場の入力(予想登録画面。基本は管理者の races の新しい列、ユーザーの上書きは prediction_notes の新しい列。
   マイグレーションが要る)と、推奨馬への足し引きを入れる。ダートの馬番の要素を同じ馬場の組の成績にする案も、そのとき一緒に判断する。

代わりの案(未実施): ユーザーが馬ごとに「道悪◎/道悪×」を手で付け、当日の馬場が道悪のときに指数を小さく(±3〜5点)足し引きする。
