# JRA PDFインポート 0件問題 修正 v4

## 原因
v3でPDFテキストをNFKC正規化した結果、JRA PDFの全角コロン `：` が半角コロン `:` に変換されます。
しかしレース境界検出は `発走時刻：` に完全一致していたため、正規化後の `発走時刻:` を検出できず、レース数が0件になっていました。

同様にコース情報も `コース：` を前提としていたため、NFKC後の `コース:` を解析できませんでした。

## 修正
- `発走時刻\s*[:：]` の両方を許容
- `コース\s*[:：]?` の両方を許容
- PDF.jsの座標行分割で日付と競馬場が別行になるケースでも、開催情報を保持するよう修正
- キャッシュバスターを更新
