2026-09-07に、肥大化した本ファイル(912行)を`docs/testing/`配下へ**機能単位で分割**しました。
本ファイルは各ファイルへのポインタ(索引)だけを持ちます。

- 対応する仕様は各ファイル冒頭に `docs/design/<機能>.md` へのリンクを記載。
