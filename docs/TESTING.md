# 手動テストチェックリスト

機能追加・修正のたびに、関係する項目を確認してください。
このファイルは恒久的なチェックリストです。新しい機能を追加したら、対応する項目をここに追記してください。

## 0. セットアップ

新規ローカルDBの場合:

```bash
npx wrangler d1 execute keiba-yosou-db --local --file=./schema.sql
```

既存ローカルDBを最新版へ更新する場合:

```bash
npx wrangler d1 execute keiba-yosou-db --local --file=./latest1.sql
```

ローカル起動:

```bash
npx wrangler pages dev public
```

## 1. CSVインポート

- 購入履歴 → CSVインポート
- 同じCSVを2回実行する
  - 1回目: レスポンスの `imported > 0`
  - 2回目: レスポンスの `skipped > 0`(重複を検知して取り込まない)
- 購入履歴に取込結果が表示されること
- 的中していない買い目も「未確定」ではなく「確定(払戻¥0)」表示になること
- CSV取込した購入履歴を削除できること(削除に失敗しないこと)
- 購入履歴に紐づくレースを削除すると、購入履歴側からもきちんと消えること
  (削除後、同じCSVを再取込した際に正しく取り込まれる=重複スキップにならないこと)

API確認:

```text
GET /api/ticket-imports
```

レスポンスが `{ ok: true, items: [...] }` の形式であること。

```text
POST /api/ticket-imports
```

`multipart/form-data` の `file` フィールドにCSVファイルを指定して取込めること。

- `sample/20260719_tohyo.csv`をインポートし、以下を確認する
  - 福島4Rのワイド(BOX・ながし)で、1行に複数の的中組み合わせがある場合に、
    組み合わせごとに正しい払戻金額が計上されること(合計が払戻金額列と一致すること)
  - 同じ受付番号・通番が別日に存在しても、日付が異なれば重複スキップされず正しく取り込まれること

## 1.5 レース登録・編集

- 新規レース登録画面で、出走馬名と着順を同時に入力して保存する
- 保存後にそのレースを編集画面で開き直し、入力した着順が保持されていること
  (以前は新規登録時のみ着順が保存されず消えてしまう不具合があった)

## 2. 予想印

- 印を変更する
- クリック直後に見た目(選択状態)が反映されること
- ページを再読込する
- 同じ印が表示されること
- 1頭に複数の印を登録できること
- 該当レースの購入馬券(買い目・購入金額・払戻金額)が一覧表示されること
  (出走馬表が未登録のレースでも、馬番ベースで表示されること)
- 購入馬券の取得に失敗しても、印の保存・「このレースの馬券を購入」への遷移に影響しないこと

## 3. 馬メモ

- メモを変更する
- ページを再読込する
- メモが残っていること

## 4. 馬券購入(組み合わせ生成)

以下の買い目生成数を確認する:

- 馬単流し 1着固定 / 2着固定
- 三連複2頭軸
- 三連単2頭軸
- 三連単マルチ

## 5. 集計(stats)

- 未確定(払戻未入力)の買い目も、購入時点で支払い済みとして収支・回収率の分母に含まれること
  (未確定分が残っている間は収支が実質マイナス表示になることを確認)
- 払戻を確定すると、収支・回収率がプラス方向へ補正されること
- 着順のみ確定(払戻レート未入力)のレースが的中率の分母に含まれること
- 着順・払戻ともに未確定のレースは的中率の分母に含まれないこと

## 6. マイグレーション整合性

- 新規DBは `schema.sql` の1回実行で最新版になること
- 既存DBは `latest1.sql` の1回実行で最新版になること
- 番号付きmigration(`archive/migrations/`)は通常のセットアップ・更新で使用しないこと

## 7. レース管理画面のレイアウト

- 開催日を開くと、競馬場が横並びのカラムで表示され、各カラムの下にR1〜12が並ぶこと
  (馬券購入ページのカレンダー選択後と同じ配置)
- 未登録のレース番号は「未登録」のプレースホルダー行として表示されること

## 8. 購入履歴のカレンダー表示

- 「📅 日付から選ぶ」でカレンダーが開閉すること
- 購入のある日に、その日の収支(千円単位、プラスは緑・マイナスは赤)が表示されること
- 日付をクリックすると、その日の購入履歴だけに絞り込まれること
- もう一度同じ日付をクリック、または「すべて表示」でフィルタが解除されること
- 前月・翌月・今日ボタンで月を移動できること
