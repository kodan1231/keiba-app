# netkeiba馬柱テキストの貼り付け取り込み(2026-10-06追加)

レース管理画面の出走馬表編集「テキストから出走馬を一括入力」に、netkeiba の馬柱ページ
(`race.netkeiba.com/race/shutuba_past.html?race_id=...`)をブラウザでコピーしたテキストを
貼り付けると、出走馬表の入力欄と、馬情報マスタ(`horses`)の血統等をまとめて埋める機能。

**経緯**: 馬情報(血統)は netkeiba(`db.netkeiba.com`)からサーバー側で1頭ずつ自動取得していたが、
2026-10-04以降 Cloudflare(アプリのサーバー)からのアクセスが継続的に拒否されるようになった
(`docs/design/data-search.md`「netkeiba連携」)。無料・手作業最小・相手の拒否をすり抜けない
という条件から、**利用者が自分で開いたページのテキストを貼り付ける**方式にした(アプリから
netkeiba へは一切問い合わせない)。馬柱ページは1ページで1レース全頭の父・母・母父を含むため、
1レース1回の貼り付けで済む。

- 画面: `public/races.html`(出走馬表モーダル)/ `public/races-entries-modal.js` / `public/parse.js`
  (`parseNetkeibaUmabashira`)。**管理者のみ**(レース管理画面自体が管理者専用)
- API: `POST /api/admin/horses/paste-import`(`functions/api/admin/horses/paste-import.js`。管理者専用)
- 調教師名エイリアス: `functions/api/_lib/trainer-alias.js`、`functions/api/admin/trainer-aliases/*`、
  管理画面「調教師名エイリアス管理」

## 貼り付けテキストの形式(馬柱ページをコピーしたもの。2026-10-06に実物で確認)

1頭ぶんのブロックは「`枠番<TAB>馬番<TAB>`」の行で始まり、次の行が続く(空行は無視):

| 行 | 例 | 意味 |
|---|---|---|
| 印 | `◯` / `◎` / `▲` / `△` / `--` | netkeiba 側の印(読み捨て) |
| 父 | `シルバーステート` | |
| 馬名 | `セイウンハーデスB` | **末尾の `B` はブリンカー着用の印**なので除去する |
| 母 | `ハイノリッジ` | |
| 母の父 | `(マンハッタンカフェ)` | 括弧を除去 |
| 所属・調教師 | `栗東・橋口` | 所属(美浦/栗東 等)と調教師の**略称** |
| 脚質・間隔 | `大中16週` | 読み捨て |
| 馬体重 | `480kg(+2)` | 読み捨て |
| オッズ | `11.2 (5人気)` | 読み捨て |
| 性齢・毛色 | `牡7黒鹿` | 性齢 `牡7` と毛色 `黒鹿` |
| 騎手 | `幸` | 騎手の**略称** |
| 斤量 | `57.0` | |
| 休養情報 | `4ヵ月休養` / `鉄砲 [1.0.0.4]` / `2走目 [...]` | 読み捨て |
| 過去走 | `17頭 13番 6人 幸英明 58.0` 等(1走7行×最大5) | 騎手名(ほぼフルネーム)だけを、騎手エイリアス候補の材料として使う |

枠順確定前で枠番・馬番が空のページは、ブロックの開始行が無いため読み取れない(枠順確定後に使う)。
馬柱形式として1頭も読み取れなければ、従来の形式(netkeiba出馬表・1行1頭)として読み取る。

## 反映内容

貼り付けて「読み込む」を押すと、すぐには反映せず**確認画面**(1頭1行。馬番・馬名・父・母・母父・
調教師・騎手と状態)を出し、「反映する」で次を行う。

| 反映先 | 項目 | 既に値があるとき |
|---|---|---|
| 出走馬表の入力欄(保存は従来どおり「保存する」) | 枠・馬番・馬名・斤量・性齢 | 貼り付けの内容で埋める |
| 出走馬表の入力欄 | 騎手 | **上書きしない**(同じ馬〈馬名一致〉の既存の行に騎手があれば残す。空欄のときだけ、エイリアスで変換したフルネーム〈未登録なら略称〉で埋める) |
| 馬情報マスタ `horses` | 父・母・母父 | 下記「上書きの扱い」 |
| 馬情報マスタ | 調教師 | **上書きしない**(空欄のときだけ、エイリアスで変換したフルネーム〈未登録なら略称〉で埋める) |
| 馬情報マスタ(`coat_color`・`affiliation` 列) | 毛色・所属 | 空欄のときだけ埋める |

過去走・オッズ・脚質・馬体重は保存しない。出走馬表の行が持つ入力欄以外の項目(性齢・斤量・
調教師等。PDF取込由来)は、モーダルで編集・保存しても消えないよう行に保持して送り返す
(2026-10-06修正。それまでは入力欄の4項目だけを送っていたため、モーダルで保存すると消えていた)。

### 上書きの扱い(父・母・母父)

- `horses` に行が無い馬: そのまま保存する(`data_source='paste'`)
- 値が空の項目: 貼り付けの値で埋める(手入力済み〈`data_source='manual'`〉の馬でも、空欄を埋めるのは上書きではないので埋める)
- 値がある項目:
  - 一致(NFKC・空白除去で比較)していれば何もしない
  - **手入力済みの馬は変えない**(確認画面に「手入力済みのため変更なし」)
  - それ以外(netkeiba取得・取込・前回の貼り付け由来)で**不一致なら、確認画面に項目ごとに
    「保存済み」と「貼り付け」を並べ、ラジオボタンで正とする方を選ぶ**(初期選択は「保存済み」)
- 失敗の記録(`fetch_error`)が残っていた行は、値を埋めたら `fetch_error` を消す。元々どの値も
  無かった行(取得失敗の行)は `data_source='paste'` にする

## 略称のエイリアス

- **騎手**: 既存の騎手名エイリアス(`jockey_aliases`。`docs/design/jockey-aliases.md`)を使う。
  登録済みの略称はフルネームに変換する(出走馬表の保存時にもサーバー側で同じ変換がかかる)
- **調教師**: 調教師名エイリアス(`trainer_aliases`。2026-10-06新設)を使う。`栗東・橋口` は
  所属 `栗東` と略称 `橋口` に分け、略称を `trainerAliasKeyOf`(NFKC+全空白除去)で引いて変換する。
  管理画面「調教師名エイリアス管理」で登録・削除できる(騎手名エイリアスと同じ形)
- **未登録の略称**: 確認画面で「未登録の略称」として示し、変換候補があれば候補を出して
  ボタン1つでエイリアス登録できる(候補は入力欄に入るので、登録前に直せる)。
  - 騎手の候補: 同じ馬の過去走に出ている騎手名のうち、略称で始まるもの(例「幸」→「幸英明」)
  - 調教師の候補: `horses` に保存済みの調教師名のうち、略称で始まるもの、または
    「略称の最後の1文字を除いた部分で始まり、最後の1文字で終わる」もの(例「手塚久」→「手塚貴久」)
  - 未登録のままでも、空欄を埋めるときは略称のまま入れる

## API(`POST /api/admin/horses/paste-import`)

リクエスト: `{ action: "preview" | "apply", horses: [{ horse_name, sire, dam, dam_sire,
trainer_abbr, affiliation, coat_color }], choices?: { <horse_name>: { sire|dam|dam_sire: "pasted"|"existing" } } }`

- 件数は1レースの出走頭数(最大18。19件以上は400)。`horses` の行は
  `horse_key IN (...)` で一度に読む(最大18バインド)。書き込みは最大18文を `db.batch()` で
- `preview`: 書き込まず、馬ごとの `status`(`new`=未登録 / `fill`=空欄を埋めるだけ /
  `same`=変更なし / `conflict`=不一致あり / `manual`=手入力済みで値の違いがある)、
  `existing`・`pasted`(調教師はエイリアス変換後)・`conflicts`(不一致の項目名)・
  `trainer: { abbr, resolved, candidates }` を返す
- `apply`: `preview` と同じ判定で、不一致の項目は `choices` に従って(指定が無ければ保存済みのまま)書き込み、
  馬ごとの結果(`inserted`/`updated`/`unchanged`)を返す

## スキーマ(`@STEP: umabashira_paste`)

- `trainer_aliases(id, alias_key UNIQUE, alias_display, canonical_name, created_at)`
- `horses.coat_color TEXT`(毛色)・`horses.affiliation TEXT`(所属。美浦/栗東 等)
