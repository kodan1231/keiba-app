# JRAレース結果PDFインポート V6 診断版

## 目的
JRA「レース結果一覧」PDFの解析が途中で停止した場合に、どの段階で止まったかを画面とブラウザコンソールで確認できるようにした診断版です。

## 解析エンジン
- Version: 6.0.0-diagnostic
- PDF.js: 3.11.174
- PDFページごとの抽出ログを記録
- レース開始候補、開催情報候補、結果行、着順、払戻を段階別に集計

## 画面上の診断
解析後に以下を確認できます。
- PDFページ数
- 抽出行数・文字数
- 開催情報候補
- 日付候補
- 「発走時刻」候補
- 発走時刻候補
- レース開始検出数
- 結果行検出数
- 1～3着検出数
- 払戻行・払戻項目数
- 返還行数
- 有効レース数
- 完全着順取得レース数
- 払戻取得レース数

さらに、以下を折りたたみ表示できます。
- 解析エラー・警告
- レース開始候補
- レース別解析結果
- 抽出テキスト候補サンプル
- PDF全文抽出テキスト
- PDF.jsの実行ログ

## ブラウザコンソール
`[JRA PDF]` プレフィックスで以下を出力します。
- ファイル名・サイズ
- PDF.js読み込み状態
- PDF.jsバージョン
- ArrayBufferサイズ
- PDFページ数
- ページごとの抽出開始・完了
- 抽出行数
- レース検出数
- 最終解析結果

## 解析ロジック
- Unicode NFKC正規化
- PDF.jsの行分割を考慮
- 「発走時刻」と時刻が別行でも最大4行先まで探索
- 日付・競馬場・開催回情報を近傍から補完
- 「発走時刻を変更」「発走時刻2分遅延」などの注記をレース開始として誤検出しない
- ページをまたぐレースブロックを処理
- 1～3着、出走馬、払戻をレース単位で診断
- レース単位で取得失敗理由を表示

## 検証
同梱サンプルをPDFレイアウト抽出相当の行データに変換して検証し、以下を確認済みです。
- `レース結果一覧　JRA.pdf`: 12レース、1～3着36件、12レース有効
- `レース結果一覧　JRA_2.pdf`: 12レース、1～3着36件、12レース有効

※ブラウザのPDF.js抽出結果は環境により異なる可能性があるため、実ブラウザで解析した際は診断情報と抽出全文を確認できます。
