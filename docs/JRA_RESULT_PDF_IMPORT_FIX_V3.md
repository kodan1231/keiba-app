# JRA PDFインポート修正 v3

## 0レース問題の原因

JRA PDFをPDF.js/PDFテキスト抽出すると、「日」「走」などが互換漢字（例: `⽇`, `⾛`）として返る場合があります。
現在版の解析器は `2026年8月1日` や `発走時刻：` を正規表現で検出していたため、互換文字のままではレース境界を1件も検出できず、解析結果が0レースになっていました。

## 修正

`public/jra-result-pdf.js` の `jraResultNormalizeText()` の先頭で `String.prototype.normalize("NFKC")` を適用し、互換文字を標準形へ正規化しました。

これにより、JRA PDFの以下のような抽出結果を標準形に変換してから解析します。

- `2026年8月1日` → `2026年8月1日`
- `発⾛時刻` → `発走時刻`
- `⼟曜` → `土曜`

## 追加対応

`races.html` の `jra-result-pdf.js` のクエリバージョンも更新し、ブラウザキャッシュで古いJSが残るのを防止しています。
