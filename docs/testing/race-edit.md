## 1.5 レース登録・編集

- 新規レース登録画面で、1〜3着セレクト(馬番)に値を入力して保存する
- 保存後にそのレースを編集画面で開き直し、入力した着順(1〜3着)が保持されていること
- 出走馬表(馬名)を1件も登録していない状態でも、1〜3着セレクトに馬番を入力するだけで
  払戻金額の入力欄が表示され、入力できること
- 1着のみ入力した状態では単勝の払戻欄だけが表示され、他の式別は
  「◯着まで入力すると表示されます」という案内が出ること
- 1〜3着すべて入力すると、三連単・三連複を含む全式別の払戻欄が表示されること
- 払戻レートを入力した後に出走頭数を変更しても、既に入力した払戻レートが消えないこと
  (該当する組み合わせが変わらない式別に限る)
- 出走頭数が5〜18頭の範囲で選択できること
- 出走頭数を選択すると、各行の枠番に初期値が自動で入ること(手動で選び直せること)
- 出走頭数を変更しても、既に入力済みの枠番・馬名・騎手が保持されること
- 着順が確定しているレースの払戻入力画面で、購入件数が0件の馬券種は
  「◯点購入」の表示が出ないこと(購入がある馬券種のみ件数が表示される)


## 7. レース管理画面のレイアウト

- 開催日を開くと、競馬場が横並びのカラムで表示され、各カラムの下にR1〜12が並ぶこと
  (馬券購入ページのカレンダー選択後と同じ配置)
- 未登録のレース番号は「未登録」のプレースホルダー行として表示されること
- ヘッダーナビは全画面共通で「馬券購入/馬券履歴/集計/レース管理」の4タブが表示されること
  (レース管理画面だけタブが変わったりしない。ただし「レース管理」「管理」タブは
  管理者のみに表示され、一般ユーザーには表示されない。詳細は「10. 複数ユーザー対応」
  の管理者権限節を参照)
- レース一覧の各行(アコーディオン内)に「馬券購入」ボタンが無いこと
  (一般ユーザー向け画面への遷移は、ヘッダーナビの「馬券購入」タブからのみ行う)
- ページ上部にカレンダーが表示され、レースが登録されている日にマークが付くこと
  (マークには「結果確定数/レース数」が表示されること)
- カレンダーで日付をクリックすると、その日のレースだけに一覧が絞り込まれること
- 「選択解除」でカレンダーの選択が解除され、全日付の一覧表示に戻ること
- **2026-08-30追加**: ヘッダーに「開催日程を一括登録」ボタンが表示されないこと
  (機能自体を廃止したため。「＋ レースを登録」ボタンから個別にレースを登録する
  導線のみが残っていること)

### 7.1 コース種別・距離の表示(いずれか一方のみ入力の場合)

- レース一覧カード・払戻モーダルの読み取り専用情報のいずれについても、以下を確認する:
  - コース種別・距離の両方を入力したレースは、従来通り「ダ2000m」のように
    両方が表示されること
  - **コース種別が未入力で距離のみ入力**したレースでも、距離(例: 「2000m」)が
    表示されること
  - 距離が未入力でコース種別のみ入力したレースは、従来通りコース種別の短縮表記
    (例: 「芝」「ダ」「障」)のみが表示されること
  - 両方とも未入力のレースは、従来通り何も表示されないこと
- 払戻モーダルを開いた際の読み取り専用情報(日付・競馬場・R・レース名の後ろ)についても、
  上記と同様の組み合わせで、区切り文字(・)を挟んで正しく表示されること
