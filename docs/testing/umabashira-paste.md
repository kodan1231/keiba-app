# netkeiba馬柱テキストの貼り付け取り込み(テスト観点)

> `docs/TESTING.md` から機能単位で分割したテスト観点。関連仕様は `docs/design/umabashira-paste.md`。

## 15. 馬柱テキストの貼り付け取り込み(2026-10-06追加)

### 15.0 前提

- `@STEP: umabashira_paste`(`trainer_aliases` テーブル、`horses.coat_color`・`affiliation` 列)は2026-10-06に本番適用済み
  (新しい環境では、これを適用してから使う。未適用だと確認画面の照合が失敗する)
- 管理者でレース管理画面を開き、対象レースの出走馬表編集を開く

### 15.1 読み取り

- netkeiba の馬柱ページ(`shutuba_past.html`)の出走馬の表をコピーして「テキストから出走馬を一括入力」に貼り付け、
  「読み込む」を押すと確認画面(1頭1行)が出ること。頭数が貼り付けた頭数と一致すること
- 馬名末尾の「B」(ブリンカー)が取り除かれていること。母父の括弧が取れていること
- 休養明けの馬(「4ヵ月休養」等の行が途中にある馬)も正しく読めること
- 従来の形式(netkeiba 出馬表のコピー・1行1頭)を貼った場合は、確認画面を出さず従来どおり入力欄に入ること

### 15.2 確認画面と反映(馬情報)

- 馬情報が未登録の馬は「新規登録」、取得失敗の記録だけがある馬は「空欄を埋める」、
  すべて一致する馬は「変更なし」と出ること
- 保存済み(netkeiba取得・前回の貼り付け)の父・母・母父と異なる項目は、「保存済み」「貼り付け」が並び、
  初期選択が「保存済み」であること。「貼り付け」を選んだ項目だけが反映されること
- 手入力済みの馬は、値の違う項目を変えず「手入力済みのため変更なし」と注記が出ること(空欄の項目は埋まる)
- 調教師が既に保存されている馬は、調教師を上書きしないこと
- 「反映する」の後、馬情報検索・馬柱でその馬の父・母・母父・調教師が表示されること。取得失敗の文言が消えること

### 15.3 略称のエイリアス

- エイリアス未登録の騎手・調教師の略称に「未登録の略称」と候補入りの入力欄・「エイリアス登録」ボタンが出ること
  (騎手は同じ馬の過去走の騎手名から、調教師は保存済みの調教師名から候補が出ること。例「手塚久」→「手塚貴久」)
- 「エイリアス登録」を押すと照合し直され、同じ略称の馬がまとめてフルネーム表示になること
- 管理画面「調教師名エイリアス管理」で登録・削除・件数表示ができること

### 15.4 出走馬表への反映

- 「反映する」で出走馬表の入力欄に枠・馬番・馬名が入り、頭数が合うこと
- 既に騎手が入っていた馬(同じ馬名の行)の騎手は変わらず、空欄だった馬だけ騎手が入ること
- 「保存する」で保存した後、出走馬表を開き直しても性齢・斤量が消えていないこと
  (PDF取込で入っていた性齢・斤量・調教師等も、モーダルで編集・保存して消えないこと。2026-10-06修正)
- 「取り込みをやめる」で確認画面が閉じ、入力欄も馬情報も変わらないこと
