# netkeibaページのブックマークレット取り込み(テスト観点)

> 関連仕様は `docs/design/netkeiba-bookmarklet.md`。PCのChromeで確認する。

## 16. netkeibaページのブックマークレット取り込み(2026-10-08追加)

### 16.1 準備
- 管理画面「netkeiba取込ブックマークレット」のリンクをブックマークバーへドラッグして登録できること。
  管理画面でリンクを押すと「ドラッグして登録してください」の案内が出ること
- netkeiba 以外のページ・対象外のページ(出馬表・オッズ等)で押すと案内が出て、何も開かないこと

### 16.2 受け取り
- 馬柱(5走)・結果のページで押すと、馬券帳のレース管理画面が新しいタブで開き、
  「〜を受け取りました: 日付 競馬場R レース名」と表示されること
- 馬券帳に未ログインの状態で押すと、ログイン後に受け取りが始まること
- 自動で受け取れなかった場合、5秒後に貼り付け欄が出て、Ctrl+V →「読み込む」で同じように取り込めること
- 管理者以外のユーザーでは「管理者のみ」の案内が出ること

### 16.3 馬柱(5走)
- 中央(例: 毎日王冠)・地方(例: ジャパンダートクラシック)とも、全頭が確認画面に出て、父・母・母父・調教師・騎手が正しいこと
- 登録済みのレースはその出走馬表編集、未登録のレースは新規登録(日付・競馬場・R・レース名・コース・距離が入る)で開くこと
- 「反映する」→「保存する」で出走馬表と馬情報が保存されること(以降は貼り付け取り込みと同じ: `docs/testing/umabashira-paste.md`)

### 16.4 結果・払戻
- 確認画面に全着順・騎手・タイム・人気・払戻(単勝〜3連単。地方の枠単は出ない)が出ること
- 中央のレースで、登録済みの出走馬表に騎手のフルネームがある馬は、略称がそのフルネームに置き換わって表示されること
- 未登録の略称にエイリアス登録欄が出て、登録すると表示がフルネームに変わること
- 「反映する」で着順・払戻・全着順の記録が保存され、そのレースを買った購入履歴の払戻が再計算されること
- 未登録のレースは新しく登録されること
- 中央の結果を取り込んでも、馬情報(調教師)が略称で上書きされないこと

### 16.5 JRA公式ページ(2026-10-10追加)

- 管理画面からブックマークレットを登録し直すこと(以前のものはJRAのページで「対象外」の案内が出る)
- JRAの出走馬一覧(出馬表)ページで押すと、確認画面に12レースの頭数・馬番の有無・登録済み/新規が出て、「登録する」で出走馬表が登録・更新されること(出走馬一覧PDFと同じ結果になること。騎手の減量記号・調教師も入ること)
- 枠順確定前のページでは馬番なしで登録され、確定後のページを取り込むと馬番・枠番が入ること
- JRAのレース結果ページで押すと、確認画面に頭数・1〜3着・払戻の種類数が出て、「登録する」で着順・払戻・全着順が登録され、購入履歴の払戻が再計算されること
- JRAの他のページ(トップ・オッズ等)で押すと「出走馬一覧またはレース結果のページではありません」の案内が出ること
